# Netflix Data Preprocessing

## Objective

The objective of this project is to clean and preprocess the Netflix Movies and TV Shows dataset using Python and Pandas. The dataset was prepared for further analysis by handling missing values, removing duplicate records, standardizing text fields, converting date formats, and validating data types.

## Dataset

**Netflix Movies and TV Shows Dataset** from Kaggle.

## Tools Used

* Python
* Pandas
* Google Colab Notebook

## Project Features

* Identified and handled missing values
* Removed duplicate records
* Standardized text columns and formatting
* Converted date fields to datetime format
* Cleaned and standardized column names
* Verified and validated data types
* Exported a cleaned dataset for analysis

## Key Insights

* The dataset contains 8,807 Netflix titles.
* Several columns contained missing values, particularly `director`, `cast`, `country`, and `rating`.
* No duplicate records were found in the dataset.
* The `date_added` column required conversion to a proper datetime format for consistency.
* Column names were already well-structured but were standardized to ensure uniformity.

## Outcome

The Netflix dataset was successfully cleaned and standardized. Missing values were handled, text formatting was improved, date fields were converted, and data types were verified. The final cleaned dataset is ready for exploratory data analysis, visualization, and machine learning applications.
